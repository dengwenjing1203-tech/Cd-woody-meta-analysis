# Cd-woody-meta-analysis

Dataset and R scripts supporting the meta-analysis of cadmium exposure effects on woody plants.

## Overview

This repository contains the dataset and R scripts used in the meta-analysis of cadmium (Cd) exposure effects on woody plants.

The dataset includes extracted data from published studies used for quantitative synthesis. The accompanying R scripts provide the workflow for data processing, effect size calculation, meta-analysis modelling, statistical analyses, and visualization.

## Contents

- `Cd_woody_meta_analysis_dataset.xlsx`  
  Extracted dataset used for meta-analysis.

- `Cd_meta_analysis_R_scripts.zip`  
  R scripts for data processing, meta-analysis, statistical analyses, and figure generation.

## Software requirements

The analyses were performed using:

- R version 4.5.1
- R package: `metafor`

Additional R packages required for data processing and visualization are specified within the scripts.

## Reproducibility

The provided dataset and R scripts allow researchers to reproduce the statistical analyses and figures presented in the associated manuscript.
